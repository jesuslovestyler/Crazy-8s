# Crazy 8s

A free Crazy 8s card game you play in your browser: match the suit or the number, change the game with an eight, and empty your hand first.

**Live:** https://jesuslovestyler.github.io/Crazy-8s/
**Home:** https://jesuslovestyler.com/

One self-contained page: no account, no ads, nothing to buy. Released into the public domain (Unlicense — see LICENSE). Built by Tyler with Noki.
